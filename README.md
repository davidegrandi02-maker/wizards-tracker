# Wizards of Mickey – Tracker

Segnapunti per il gioco di carte Wizards of Mickey. App web installabile (PWA), senza build: solo file statici.

## Pubblicare su GitHub Pages
1. Carica il contenuto di questa cartella nella root di un repository.
2. Settings → Pages → Source: branch `main`, cartella `/ (root)`.
3. Apri l'indirizzo `https://<utente>.github.io/<repository>/` e, da telefono, scegli "Aggiungi a schermata Home".

## File
- `index.html` – l'app
- `manifest.webmanifest`, `sw.js` – installazione e uso offline
- `icons/` – icone dell'app
